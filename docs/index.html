wandr

A portable UI runtime for WASM apps. Write a UI once — in any language, with any framework — compile it to a single WASM component, and run it natively on any OS wandr has a backend for.

Get started View on GitHub ▶ Demo video

The one idea

A guest app imports a fixed set of OS-agnostic WIT contracts (render, input, IME, chrome, device, media, audio, events) and never names an OS. wandr-host — wasmtime + the component model + a Skia rendering core — implements those contracts and delegates only the physically OS-specific bits to a per-OS backend. The contracts are portable; only the backend is OS-specific — so the same guest .wasm runs everywhere.

Shipped guest frameworks: Compose · Slint · dioxus · Avalonia · Swift/OpenSwiftUI. Android is the production backend (post-ART, a rooted dev target); Linux · macOS · Windows are the desktop way to try wandr.

Install desktop

Installs the wandr-host runtime and the wandr app manager into ~/.wandr/bin, and adds it to your PATH.

Linux / macOS

curl -fsSL https://raw.githubusercontent.com/harryzz/wandr-host/main/install.sh | sh

Windows (PowerShell)

irm https://raw.githubusercontent.com/harryzz/wandr-host/main/install.ps1 | iex

Video playback needs GStreamer — see the full install & usage guide for the per-OS command.

Install & run apps

Open a new terminal (so PATH is picked up), then:

wandr listapps in the registry (● = installed)
wandr install <id>download + install an app
wandr run <id>run an installed app
wandr remove <id>uninstall
wandr install wandr.tetris wandr run wandr.tetris
