For a WIT function `render: func(source: string) -> document` where `document = record { blocks: list<block> }`:

- **Export side** (the producer's compiled function): `(param i32 i32) (result i32)` — 2 i32s for the lowered string (ptr, len); returns a single i32 pointer to a callee-allocated return area in the producer's linear memory. The consumer reads through that pointer.
- **Import side** (the consumer's `@WasmImport` declaration): `(param i32 i32 i32) (result )` — 3 i32s (string_ptr, string_len, **return_area_ptr**); the *caller* allocates the return area in its OWN linear memory; the dep writes into it via the canonical-ABI `cabi_realloc` hook.

Wasmtime's component-model Linker layer bridges the two — the proxy generated by host-side `Linker::instance(...).func_wrap(...)` (task 36 `wire_dep_into_linker`) translates from import to export shapes transparently.

**Why:** task 36 step 6 — initial `@WasmImport` had the export shape (`(Int, Int) -> Int`). `wasm-tools component embed --world ... <kotlin.wasm>` rejected with:
```
type mismatch for function `render`: expected `[I32, I32, I32] -> []` but found `[I32, I32] -> [I32]`
```
Fixed by switching to 3 i32 params + caller-allocated 8-byte return area (document is `record { blocks: list<…> }` → list lowers to ptr+len = 8 bytes).

**How to apply:**

- When hand-writing WIT IMPORTS in any language (Kotlin/Wasm, raw Rust without bindgen, etc.), the signature follows caller-allocated rules: rich return values pass via an extra trailing pointer arg; the function returns nothing (or just inline-direct slots if the result fits in ≤16 bytes).
- Small results may use multivalue returns; Kotlin/Wasm and some other toolchains don't support multivalue. For records/lists/variants, default to indirect return (caller-allocated, extra pointer arg).
- The return-area layout follows the WIT record's field offsets and alignments:
  - `record { blocks: list<block> }` → offset 0 = `blocks.ptr` (i32), offset 4 = `blocks.len` (i32), total 8 bytes, 4-byte aligned.
  - Larger records: lay out each field per its native alignment, packed.
- Check the producer's compiled wasm signature via `wasm-tools print <wasm> | grep '$<interface>#<name>'` to confirm the export shape, then derive the importer signature: **prepend** a return-area-pointer param, **drop** the return slot.
- The matching `cabi_post_<interface>#<name>` export is the cleanup hook the caller can invoke after reading the result. One-shot consumers can skip it (process exit frees everything).

Working example: `wandr-app-md-smoke/src/wasmWasiMain/kotlin/generated/MarkdownImports.kt` documents the symmetry inline alongside the call.
